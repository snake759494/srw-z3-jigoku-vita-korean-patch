# 제3차 슈퍼로봇대전 Z 시옥편 한글패치 — 새 프로젝트

이 폴더는 기존 작업을 버리는 곳이 아니라, 흩어진 Python 코드와 XLSX를 안전한 한 흐름으로 다시 정리하는 작업공간입니다. 기존 `PCSG00264` 폴더는 읽기 전용 자료로 두고 경로만 연결합니다.

처음 시작할 때는 [START_HERE.md](START_HERE.md)를 읽거나 `시작하기.cmd`를 더블클릭하세요.

## 공개 저장소 안내

이 공개 저장소는 `scripts/export_public_tree.py`가 만든 **정제본**입니다. 권리자 자료를 싣지 않기 위해 다음을 제외했습니다.

- 번역 JSON의 일본어 원문(`sourceText`). 원문 대조용 `sourceTextSha256`과 제어문자 목록 `controls.sourceTokens`만 남깁니다.
- 원문을 통째로 품은 시나리오별 일회성 재번역 스크립트(`scripts/retranslate_stg*`, `retranslate_dlc*` 등).
- 원본·완성 게임 파일, `cpkmakec.exe` 같은 사유 도구, 개인 경로.

그래서 이 저장소만으로는 CPK를 만들 수 없습니다. 빌드는 본인이 합법적으로 보유한 `PCSG00264` 원본과 도구가 있는 로컬 작업본에서 합니다. 오프라인 대사 뷰어는 원문 열을 숨긴 채 기존 번역과 신규 번역을 비교·편집할 수 있고, 제어문자 검사는 저장된 토큰 목록으로 동작합니다. 원문이 있어야만 성립하는 검사 3개는 공개 데이터에서 자동으로 건너뜁니다.

번역문의 공개 라이선스와 기존 번역 기여자 동의는 [NOTICE.md](NOTICE.md)에 적힌 대로 아직 확정되지 않았습니다.

## 이번 정리 결과

- 본편 265개, DLC 77개, 사전 1개 등 XLSX 343개를 모두 인식했습니다.
- 원문 175,210행을 중복 없는 고유 ID와 XLSX SHA-256이 포함된 TSV로 옮겼습니다.
- Git 게시용으로 일본어 원문 전문을 제외하고 원문 SHA-256만 남긴 175개 자산별 번역 corpus를 만들었습니다.
- 174,817행은 구조상 정상적으로 이관했고, 제어 토큰 125행과 기록 길이 초과 268행 등 총 393행은 `blocked`로 격리했습니다.
- 새 공용 코드와 통합 실행기의 단위 테스트 91개가 통과했습니다.
- 전체 175,210행(본편 156,565행, DLC 14,181행, 사전 4,464행)을 일본어 원문에서
  새로 번역한 draft 오버레이 175개 자산으로 채웠습니다.
- 별도 추가 자산으로 `eboot.bin` 2개, AID/RPW/SRVC 바이너리와 `KDataVITA` 및
  `MtZkn_KW/Pt/Rt` CPK 내부 파일까지 844개 자산, 62,937행을 같은 원문 기준
  재번역 작업으로 분리했습니다. 결과는 `translations/retranslation-extra/`에
  두며 원본 CPK·EBOOT는 저장소에 넣지 않습니다.
- 추가 오버레이 844개를 전체 기준 TSV와 대조해 ID·원문 결박·제어 토큰 검사를
  통과했습니다. 조각 보정 후에도 가나 잔류 248행(408자)은 고유명사·문자표
  시험 문자열이 섞인 수동 검수 대상으로 표시되어 있습니다.
- 기존 번역은 `references` 안의 참고 자료로만 보존하고 새 번역 생성에는 자동 재사용하지
  않았습니다. 이번 시나리오 전면 재번역은 외부 온라인 번역 API를 사용하지 않고,
  저장소의 일본어 원문과 로컬 작업 흐름만으로 새 초안을 만들었습니다. 잔류 일본어·
  고유명사·제어기호는 QA 플래그와 참고 번역 보완 기록을 남겨 사람 검수 대상으로
  분리했습니다.
- `STG0001a` 93행만 기존 독립 교차검수 완료(`reviewed`)이고, 나머지 174개 자산은
  모두 `draft`로 남겨 사람 검수 후에만 적용하도록 했습니다.
- 기호형 제어 토큰 복원 및 재번역 JSON 검사를 통과했고, 전체 단위 테스트 91개가 통과했습니다.
- 시나리오 전면 재번역은 `translations/dialogue/scenario_*.json` 174개 파일,
  170,746개 항목을 공통 JSON에 반영했습니다. 원문 불일치·누락·제어코드 불일치·
  빈 번역은 0건이며, 세부 플래그와 재실행 명령은
  [시나리오 전면 재번역 지침](docs/시나리오_전면재번역_지침.md)에 기록했습니다.
- 원본 8GB 아카이브와 게임 바이너리는 새 폴더로 복사하거나 수정하지 않았습니다.
- 사용자 제공 `SRVC.BIN` 전투 대사 번역표도 같은 경계로 정리했습니다. 고유 대사
  25,758행·슬롯 31,983행을 일본어-한국어 쌍 JSON과 고정 슬롯 델타로 보관하고,
  원본 XLSX와 게임 BIN은 해시만 기록했습니다.
- 미추출 상태였던 사전 대사를 `MtZkn_KW.cpk`에서 직접 찾아냈습니다. ITOC 141개
  멤버와 `WORD/SRCE/DSCR/DSC2` 564개 태그를 `0x5E` XOR 해제해 일본어-한국어
  쌍 JSON으로 만들고, 긴 설명까지 손실 없이 CPK 리팩하는 실행기를 추가했습니다.
  564개 행은 모두 번역 초안으로 채웠으며(`draft` 280개, `overflow-repacked` 284개),
  고유명사와 문장 품질은 사람 검수 대상으로 표시했습니다.
- 시나리오·전투·사전 대사를 동일한 `siok.dialogue-review` JSON 형식으로
  `translations/dialogue/` 한 폴더에 모았습니다. 원문·번역·제어 토큰·위치·
  페이로드 해시를 한 행에서 확인하고 `translation`만 수정할 수 있습니다.

## 지금 가능한 것

- 기존 스테이지·DLC·사전 XLSX를 UTF-8 TSV로 가져오기
- 파일명·시트명·원본 XLSX 해시를 함께 기록해 출처 보존
- 제어 토큰, 빈 번역, 행 ID, 기록된 길이와 상태를 검사
- TBL/WReplace 중복과 미등록 문자를 엄격하게 거부하는 공용 코덱 사용
- 고정 길이 바이너리 패치에서 범위·겹침·길이·원본 바이트를 검사
- 기존 본편/DLC 해시 스냅숏과 xdelta를 안전하게 검증
- 대사 XLSX를 원본 행·태그·raw 해시가 결박된 정규 JSON으로 만든 뒤 명시적 ID로 리팩
- 성공한 `dialogue-manifest.json`만으로 XLSX 없이 같은 대사 CPK를 재빌드
- 완성 CPK를 다시 추출해 모든 ID와 payload SHA-256을 자동 검증
- 기존 번역을 자동 재사용하지 않는 원문 결박형 재번역 JSON 생성·검사·누적 병합
- 제어 토큰 사이의 긴 목록을 조각으로 나누어 추가 재번역하는 보정 스크립트
- GitHub의 SRVC JSON과 Python 표준 라이브러리만으로 자기 소유 원본 `SRVC.BIN`을
  해시 검증 후 `output/`에 패치하는 독립 실행기
- `config/release-patch.json`의 253개 항목(본편 222개 xdelta, DLC 29개 xdelta,
  전투 대사 JSON 1개, 사전 JSON 1개)을 공식 xdelta3와 한 번에 적용하는 통합 실행기
- `eboot.bin`, 메뉴·기체명 CPK, 64개 맵, `param.sfo`, 본편·DLC 시나리오 CPK까지
  원본 해시와 결과 해시를 모두 확인하는 Vita3K용 별도 출력 트리
- 공식 xdelta3 ZIP과 실행 파일을 고정 SHA-256으로 확인해 `private/tools/`에 준비하는
  `scripts/prepare_xdelta3.py`

## 현재 릴리스 범위와 남은 항목

- 공개 Vita3K 실행기는 본인 소유 1.02 원본의 해시가 매니페스트와 일치할 때만 동작함
- `MtZkn_Pt/Rt` 등 추가 재번역 초안은 아직 사람 검수·CPK 적용 대상이 아님
- 폰트·텍스처의 재배포 권리와 별도 GXT 생성 옵션은 이 저장소 범위에 포함하지 않음
- 실기 Vita의 eboot 서명·패키지 생성 절차는 미완성이며 프로필을 명시적으로 차단함

실제 적용 명령과 입력 폴더 규칙은 [통합 패치 실행](docs/통합_패치_실행.md)을
따릅니다. 실행 결과는 `output/release-candidate/` 아래에만 만들고 게임 설치 폴더에는
자동으로 복사하지 않습니다.

## 폴더 구분

| 폴더 | 용도 | Git |
|---|---|---|
| `src/siok_patch` | 새 공용 Python 코드 | 저장 가능 |
| `config`, `manifests` | 공개 설정과 해시 기준 | 저장 가능 |
| `translations` | 번역 corpus와 SRVC 원문-번역 쌍·델타 자료 | 공개 범위별 권리 안내 적용 |
| `patches/release/vita3k` | 원본을 포함하지 않는 본편·DLC xdelta | 공개 가능 델타만 |
| `private` | 개인 경로와 권리 검토 중인 입력 | 저장 금지 |
| `work` | 가져온 TSV, 검사 보고서, 스테이징 | 저장 금지 |
| `output` | 검증 오버레이와 배포 후보 | 저장 금지 |

기존 조사 근거는 `docs/legacy`와 `legacy/reports`에 보존했습니다.

대사 CPK의 새 일괄 과정은 [대사 CPK 자동화](docs/대사_CPK_자동화.md)를 참고하세요.

새 대사 번역은 [신규 대사 번역](translations/retranslation/README.md)에서 시작하세요.

시나리오 전체 재번역 초안과 문맥·용어·대사창 길이 검수는
[시나리오 전면 재번역 지침](docs/시나리오_전면재번역_지침.md)을 따릅니다.
엑셀 자료를 통합한 용어사전은 [시나리오 용어사전 v2](docs/시나리오_용어사전_v2.md),
재번역 실행 절차는 [시나리오 재번역 v3](docs/시나리오_재번역_v3.md)에 정리했습니다.

시나리오 JSON을 게임 대사창처럼 확인하려면
[시나리오 대사 HTML 뷰어](viewer/시나리오_대사_뷰어.html)를
`viewer/시나리오_대사_뷰어_실행.cmd`로 실행하고,
[사용 설명](viewer/README.md)의 카탈로그 갱신 절차를 참고하세요.

추가 CPK·`eboot.bin` 재번역은 [추가 자산 재번역](translations/retranslation-extra/README.md)을
참고하세요. 이 결과도 자동 초안(`draft`)이므로 사람 검수 후에만 바이너리에 적용합니다.

전투 대사 `SRVC.BIN` 번역표와 적용 결과의 해시·역검증 과정은
[SRVC 전투 대사 번역 보관](docs/전투대사_SRVC_번역.md)을 참고하세요.

사전 대사의 `MtZkn_KW.cpk` 탐색, `0x5E` XOR 해제, 신규 번역, 태그 길이·ITOC
갱신과 리팩 과정은 [사전 대사 추출과 패치](docs/사전_대사_추출과패치.md)에
정리했습니다.

세 대사 종류를 사람이 검수할 공통 JSON 목록과 수정 규칙은
[공통 대사 검수 폴더](translations/dialogue/README.md)를 참고하세요.

세 영역과 적용 파일 전체를 한 번에 만드는 방법은 [통합 패치 실행](docs/통합_패치_실행.md)에
정리했습니다. `patches/release/vita3k/`에는 원본·완성 게임 파일이 아닌 xdelta만 보관합니다.

작업 우선순위는 [다음 작업](docs/다음작업.md)에 정리했습니다.
