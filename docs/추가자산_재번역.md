# 추가 CPK·`eboot.bin` 재번역

기존 본편·DLC 대사 외의 바이너리 문자열도 동일한 원칙으로 분리해 재번역한다.
원본 XLSX의 일본어 원문을 기준으로 새 번역을 만들고, 기존 번역 열은 `references`
안에서만 보존한다.

## 대상 범위

| 범위 | 대상 |
|---|---|
| `eboot` | `eboot.bin`의 SJIS/UTF-8 문자열 XLSX |
| `aid` | `AIDDataPack.cpk` 내부 ID00000·ID00004·ID00010~40 |
| `rpw` | `rpw_data.cpk` 통합 XLSX |
| `srvc` | `SRVC.BIN` 통합 XLSX |
| `kdata` | `D_KDataVITA.cpk` 5개 XLSX |
| `mtzkn_kw`·`mtzkn_pt`·`mtzkn_rt` | 각 `MtZkn_*.cpk` 내부 파일 XLSX |

현재 기준선은 844개 자산, 62,937행이다. 정확한 파일별 SHA-256과 시트·행 수는
`translations/retranslation-extra/source-manifest.json`에 기록한다.

## 실행

```powershell
$env:PYTHONPATH='src'
python scripts/import_extra_retranslation.py --archive-root '<로컬 아카이브 경로> Ho Lee\Desktop\Z\PCSG00264'
python scripts/auto_translate_retranslation.py `
  --source work/extra-normalized/translations.tsv `
  --task-root work/retranslation-extra/tasks `
  --output-root translations/retranslation-extra `
  --workers 6 --max-chars 4000
python scripts/repair_retranslation_japanese.py `
  --source work/extra-normalized/translations.tsv `
  --task-root work/retranslation-extra/tasks `
  --output-root translations/retranslation-extra `
  --workers 6
python scripts/repair_retranslation_segments.py `
  --source work/extra-normalized/translations.tsv `
  --task-root work/retranslation-extra/tasks `
  --output-root translations/retranslation-extra `
  --workers 8 --max-chars 1200
```

두 번째 명령은 이미 오버레이가 있는 자산을 건너뛰므로 중단 후 같은 명령을 다시
실행할 수 있다. 세 번째 명령은 자동 결과에 남은 일본어 문자를 원문 기준으로
다시 요청한다. 번역 결과는 모두 `draft`로 남기며, 빈 결과·제어 토큰 불일치·긴급
보류 행은 사람 검수 대상이다.

## 저장 경계

- `work/extra-normalized/`와 `work/retranslation-extra/tasks/`에는 원문과 기존
  번역 열이 있어 Git에 올리지 않는다.
- `translations/retranslation-extra/`에는 공개 가능한 새 번역과 원문 해시만 둔다.
- 원본 CPK, `eboot.bin`, ROM/VPK는 저장소에 복사하거나 커밋하지 않는다.
- 이 오버레이는 실제 리팩·패치 전 검수용이며, 검수 전에는 배포 후보로 사용하지 않는다.
