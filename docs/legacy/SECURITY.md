# 보안 지침

## 발견된 자격 증명 후보

원본 아카이브 루트에 `gen-lang-client-*.json` 파일이 있습니다. 정적 구조 검사 결과 서비스 계정의 비공개 키와 계정 정보 필드를 가진 자격 증명 파일입니다. 비밀값 자체는 출력하거나 새 프로젝트로 복사하지 않았습니다. 또한 루트의 `trans-test.py`와 `g.py`에는 API 비밀값으로 보이는 평문 리터럴이 있습니다.

권장 조치:

1. 해당 클라우드 프로젝트와 API 공급자에서 키 상태를 확인합니다.
2. JSON 키와 두 Python 파일의 키를 즉시 폐기하고 필요할 때만 새 키를 발급합니다.
3. 새 키는 저장소 밖의 비밀 저장소나 환경 변수로 전달합니다.
4. Git 히스토리에 들어간 적이 있다면 단순 삭제로 끝내지 말고 키를 폐기합니다.

값을 노출하지 않고 후보 위치만 다시 검사하려면 다음 명령을 사용합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Find-SecretCandidates.ps1 `
  -SourceRoot 'C:\path\to\PCSG00264' `
  -OutputPath .\reports\generated\secret-candidates.json
```

이 명령은 원본 아카이브에 되쓰지 않지만 지정한 보고서 파일은 생성하거나 덮어씁니다. `.gitignore`는 알려진 이름 패턴을 보조적으로 차단할 뿐 평문 비밀값을 모두 탐지하거나 기존 키를 폐기해 주지 않습니다.

## 실행 파일

기존 아카이브의 EXE는 자동으로 실행하지 않습니다. 이름이 같은 도구라도 공식 배포처에서 다시 받고 다음 정보를 `tools.lock.json` 같은 공개 메타데이터에 기록해야 합니다.

- 공식 URL과 버전
- 다운로드 일시
- SHA-256
- 라이선스
- 사용 목적과 호출 인자

특히 `_decrypt.exe`, `psvpfsparser-win64.exe`, GXT 변환기, Vita ELF 도구는 출처 검증 전 격리 대상으로 봅니다.

`psp2gxt.exe`는 바이너리 내부에 독점 SDK 및 기밀성 관련 문구가 확인되어 공개 저장소나 배포 패키지에 포함하지 않습니다.

일부 XLSX에는 작성자·최종 편집자 개인 이름 메타데이터가 남아 있습니다. 번역 원고를 공개할 경우 내용뿐 아니라 문서 속성도 별도로 제거·검토합니다.

## 원본 데이터

- 원본 아카이브는 읽기 전용 권한 또는 별도 백업으로 보호합니다.
- 게임에서 파생된 빌드·오버레이는 `build/` 또는 저장소 밖의 전용 출력 경로에 만듭니다.
- 로컬 조사 보고서는 `reports/generated/`, 임시 디코딩 파일은 `.local/tmp`에 만들며 둘 다 Git 추적에서 제외합니다.
- 기준 매니페스트 재추출은 매번 새 `reports/generated/manifests-*` 디렉터리에 수행합니다. `Export-LegacyManifest.ps1`은 추적 중인 `manifests/`와 기존 출력 디렉터리를 덮어쓰지 않습니다.
- xdelta를 실행하는 `Test-XdeltaRoundTrip.ps1`과 `New-PatchOverlay.ps1`은 `config/tools.lock.json`에 고정된 실행 파일 해시를 검사합니다. 기존 아카이브 안의 xdelta/EXE는 사용하지 않습니다.
- 조사·검증 스크립트도 출력이 원본 아카이브나 게임·패치 입력 경로 안이면 중단합니다. 그래도 실행 전 실제 경로와 링크/정션 여부를 확인합니다.
- 공개 배포 전에 압축 파일의 목록을 검사해 원본, `.bak`, 키, 사용자 경로가 포함되지 않았는지 확인합니다.

## 권리와 재배포

- 델타는 게임 원본 파일을 패키지에 직접 포함하지 않는 배포 형식일 뿐, 자동으로 저작권·재배포 문제가 해소되는 것은 아닙니다. 델타 내용과 적용 안내를 배포 전 별도로 검토합니다.
- 델타 적용에는 사용자가 합법적으로 보유한 정확한 `PCSG00264` 1.02 원본이 필요하며, 입력 SHA-256이 다르면 중단합니다.
- 현재 저장소에는 프로젝트 `LICENSE`가 없습니다. 코드, 문서, 번역문, 텍스처, 폰트, 델타 및 외부 도구에 대한 재배포 허가는 부여되지 않았습니다.
