# 시나리오 재번역용 용어사전 v2

이 문서는 시나리오 대사를 다시 번역할 때 사용하는 기준서다. 실제 게임 파일이나
롬 이미지는 저장하지 않고, `D:\\Z\\psvita\\시옥번역엑셀`에 있는 작업표를 읽어
일본어 원문과 한국어 작업값을 쌍으로 정리한다.

## 산출물

- [`scenario_glossary_v2.json`](../translations/retranslation/scenario_glossary_v2.json):
  인물·파일럿·기체·무기·용어·공용 문자열의 일본어/한국어 쌍, 출처 행, 후보 번역,
  인물 관계, 작품별 말투 지침을 담은 기계 판독용 사전
- [`scenario_glossary_v2.schema.json`](../translations/retranslation/scenario_glossary_v2.schema.json):
  JSON 구조 검증 스키마
- [`build_translation_glossary.py`](../scripts/build_translation_glossary.py):
  원본 XLSX를 수정하지 않고 사전을 재생성하는 추출기
- [`reference_rules.json`](../translations/retranslation/reference_rules.json):
  7개 XLSX의 SHA-256, 시트별 편집 열, 재삽입 필드, 바이트·제어문자·공백 규칙을
  기계 판독 형식으로 고정한 기준 파일
- [`series_reference.json`](../translations/retranslation/series_reference.json):
  32개 참전작의 설정·핵심 인물 관계·말투·존칭 지침과 외부 자료 URL을 담은 번역
  참고 자료
- [`참전작_설정_관계_말투_참고.md`](참전작_설정_관계_말투_참고.md):
  번역자가 빠르게 확인하는 사람용 요약표

원본 파일의 SHA-256과 파일명은 JSON의 `sourceFiles`에 기록한다. 따라서 원본 작업표가
갱신되면 같은 명령으로 사전을 다시 만들고 해시 변화를 검토할 수 있다.

2026-08-14 재점검에서 `D:\\Z\\psvita\\시옥번역엑셀`의 7개 파일과 19개 시트를
확인했다. 현재 `scenario_glossary_v2.json`은 이 7개 파일에서 재생성한 결과와
일치하며, 외부 작품 자료는 게임 원문을 덮어쓰는 우선순위가 아니라 관계·말투를
판단하는 보조 자료다.

```powershell
python scripts/build_translation_glossary.py `
  --excel-root "D:\\Z\\psvita\\시옥번역엑셀"
```

## 번역 우선순위

1. 일본어 원문과 게임 필드 의미를 확인한다.
2. 같은 일본어 표기의 `preferredKo`를 사용한다. `koCandidates`와 `aliasesKo`는
   과거 표기와 검수 참고용이며 자동으로 덮어쓰지 않는다.
3. 인물명은 인물 사전의 CHFN/CHNN 표기를, 파일럿·기체·무기명은 해당 도감과
   공용 문자열의 표기를 우선한다.
4. 파계사변·재세전쟁·시옥전쟁, UCW/ADW, ZEUTH/ZEXIS/Z-BLUE처럼 세계관을
   구분하는 용어는 JSON의 `context`와 `project_term` 기록을 따른다.
5. 기존 손번역은 문장 흐름과 고유명사 후보를 확인하는 참고 자료로만 사용한다.
   문장을 자동 복사하거나 외부 번역 서비스에 전송하지 않는다.
6. 참전작의 작품별 관계·말투가 필요한 경우 `series_reference.json`의 해당 `id`를
   먼저 확인하고, 그 다음 `speechProfiles`와 장면의 화자/청자를 대조한다.

## 인물 관계와 말투

`speechProfiles`는 인물별 기본 말투와 존칭 경향을, `relationships`는 관계가 바뀔 때
우선할 호칭과 거리감을 기록한다. 예를 들면 다음과 같다.

- 히비키→스즈네: 처음에는 선생님에 대한 존중을 남기되, 감정이 격해질수록 반말이
  섞인다. 한 장면 안에서 호칭을 임의로 바꾸지 않는다.
- 소스케→카나메: 소스케는 군인식 단정문을 유지하고, 카나메에게는 이름을 부르며
  일상 대화에서는 조금 누그러진다. 카나메는 소스케를 타박할 때 빠른 반응과
  반말을 사용한다.
- 키라·신·아스란: 전투 중에는 짧은 명령형을 사용하지만, 과거의 적대 관계와
  동료로 인정한 현재의 관계가 대사에 함께 드러나도록 한다.
- 아무로·카미유·샤아: 계급·전우 관계와 작품의 절제된 군인 말투를 우선한다.
  샤아의 비유와 여유를 평범한 설명문으로 평탄화하지 않는다.
- 알토·셰릴·란카: 셰릴의 자신감과 란카의 풋풋함을 구분하고, 알토가 두 사람을
  부르는 방식도 장면의 관계에 맞춘다.

이 지침은 기계 번역 결과를 생성하기 위한 규칙이 아니라, 사람이 문장 전체를
검토할 때 화자와 상대를 놓치지 않기 위한 체크리스트다.

## 대사 길이와 제어문자

시나리오 JSON의 각 항목에 있는 `metadata.byteLimit`, `controls`를 원문과 함께
확인한다.

- 제어문자(`⑲`, `⑳`, `㊥`, `㊦`, `㊧`, `㊨`, `$n`, `$l`, `$c`, `$F` 등)는 종류·개수·순서를
  바꾸지 않는다.
- 줄바꿈과 표시 줄 수를 먼저 맞춘 뒤 한국어 문장을 다듬는다. 한 줄을 억지로
  채우기보다 짧고 자연스러운 문장을 선택한다.
- `encodedLength`가 한도보다 크면 동의어를 줄이고, 수식어와 중복 주어를 덜어낸다.
  고유명사나 제어문자를 삭제해서 길이를 맞추지 않는다.
- 번역 편집 시에는 반각 일반 공백(U+0020)을 사용한다. 최종 게임 삽입 단계에서만
  패치 코드가 반각 공백을 0xFEFE로 변환하므로, XLSX/JSON 단계에서 전각 공백을
  섞지 않는다.
- 일본어가 남아 있는 항목, 후보 번역이 서로 충돌하는 항목, 존칭이 장면 앞뒤에서
  흔들리는 항목은 `draft`로 남겨 사람이 확인한다.

## 검증

사전 생성 뒤 다음을 확인한다.

```powershell
python -m json.tool translations/retranslation/scenario_glossary_v2.json > $null
python -m json.tool translations/retranslation/scenario_glossary_v2.schema.json > $null
pytest -q
```

기준 파일 자체도 함께 검사한다.

```powershell
python -m json.tool translations/retranslation/reference_rules.json > $null
python -m json.tool translations/retranslation/series_reference.json > $null
python scripts/validate_translation_references.py `
  --excel-root "D:\\Z\\psvita\\시옥번역엑셀"
```

`scenario_glossary_v2.json`에는 원본 게임 파일과 CPK가 없으며, 번역에 필요한
텍스트 쌍·규칙·해시만 포함한다. 이후 시나리오 재번역 도구는 이 사전을 읽어
고유명사 정규화와 길이·제어문자 검사를 수행한다.
