# 시나리오 대사 전면 재번역 지침

이 문서는 `translations/dialogue/scenario_*.json`의 일본어 원문을 기준으로
시나리오 대사를 새로 번역하고, 실제 대사창에 들어가는 길이와 제어코드를
검사하기 위한 작업 기준이다. 게임 원본·덤프·실행 파일은 저장소에 넣지
않으며, 반드시 본인이 소유한 게임에서 추출한 파일만 사용한다.

## 번역 범위와 원칙

- `sourceText`가 유일한 번역 입력이다. 기존 `translation`, `googleTranslation`,
  `legacyTranslation`, `importedTranslation`은 고유명사·문맥을 확인하는
  참고 자료일 뿐, 문장을 복사하는 원본이 아니다.
- 한 행만 보고 직역하지 않는다. 같은 `internalId`와 인접 `sourceRow`를 함께
  읽어 장면의 화자·상황·앞뒤 인과를 파악한다.
- 화자별 말투는 `translations/retranslation/glossary.json`을 우선한다. 이름은
  한글 표기를 고정하고, 일본어식 존칭을 한국어의 관계에 맞게 자연스럽게
  옮긴다.
- `⑲`, `⑳`, `㊥`, `㊦`, `㊧`, `㊨`, `$n`, `$l`, `$c` 같은 게임 제어코드는
  종류·개수·순서를 바꾸지 않는다. 번역문에 새 제어코드를 만들지 않는다.
- 원문의 행 분할을 임의로 합치거나 나누지 않는다. 여러 행으로 이어진 문장도
  전체 의미를 먼저 파악한 뒤 기존 `entryId` 경계를 그대로 유지한다.
- 번역 상태는 사람이 실제로 검수하기 전까지 `draft`다. 인코딩 표와 실제
  패치 대상에서 길이 검사를 통과하기 전에는 `approved`로 올리지 않는다.

## 세계관·사건 기준

제3차 슈퍼로봇대전 Z 시옥편은 Z 시리즈의 네 번째 작품이며, 신다원세기의
시옥전쟁을 다룬다. UCW와 ADW가 융합된 다원세계, ZEUTH·ZEXIS의 계승 관계,
스피어와 낙인, 다원전쟁의 시간 순환을 한 용어 체계로 유지한다. 에피소드
순서와 분기·DLC 위치는 공개 시나리오 목록을 대조한다.

- [Z 시리즈 개요](https://srw.wiki.cre.jp/wiki/Z%E3%82%B7%E3%83%AA%E3%83%BC%E3%82%BA)
- [시옥전역 사건 연표](https://srw.wiki.cre.jp/wiki/%E6%99%82%E7%8D%84%E6%88%A6%E5%BD%B9)
- [시옥편 시나리오·분기 목록](https://w.atwiki.jp/srwz_3rd/pages/31.html)

위 자료는 고유명사·연표·분기 위치를 확인하기 위한 참고 자료다. 게임 대사의
문장 자체는 저장소의 일본어 원문을 우선한다.

## 고정 용어와 인물 표기

핵심 표기는 다음 원칙으로 통일한다. 전체 용어집은
`translations/retranslation/glossary.json`에서 관리한다.

| 일본어 개념 | 한국어 표기 |
| --- | --- |
| 時獄戦役 / 時獄篇 | 시옥전쟁 / 시옥편 |
| 破界事変 / 再世戦争 | 《파계사변》 / 《재세전쟁》 |
| 時空震 / 大時空震 | 시공진동 / 대시공진동 |
| 多元世界 / 平行世界 | 다원세계 / 평행세계 |
| 次元の壁 / 次元の檻 | 차원의 벽 / 차원의 새장 |
| スフィア / スフィア・リアクター | 스피어 / 스피어 리액터 |
| ZEUTH / ZEXIS / UCW / ADW | 원문 대문자 유지 |

신은 직선적이고 감정적인 반말, 키라는 온화한 반말, 카미유는 동료에게
반말·상관에게 존댓말, 아무로는 침착한 단정체, 로저는 지적이고 무게감 있는
말투를 기본으로 한다. 장면에서 실제 관계가 바뀌면 장면의 관계를 우선한다.

## 대사창 길이 기준

JSON의 `metadata.byteLimit`이 있으면 하드 제한으로 기록하고, 없으면
`metadata.encodedLength`와 원문 길이를 참고해 불필요한 수식어를 줄인다. 줄임은
의미를 훼손하지 않는 범위에서만 하며, 생략부호·문장부호를 포함한 최종 문장을
사용한다. `work/retranslation-v2*/qa-report.json`의 `lengthOverflow`와
`markerMisses`를 먼저 해결한 뒤 패치 빌드로 넘어간다.

## 재현 가능한 흐름

```powershell
# 1) 공통 JSON 검증
python scripts/check_dialogue_review_bundle.py

# 2) 번역 결과가 준비된 경우 원문 SHA-256·제어코드·길이 검사
python scripts/apply_scenario_retranslation_v2.py `
  --work-root work/retranslation-v2

# 3) 검사 결과를 확인한 뒤에만 공통 JSON에 병합
python scripts/apply_scenario_retranslation_v2.py `
  --work-root work/retranslation-v2 --apply

# 4) 통합 테스트
python scripts/check_dialogue_review_bundle.py
python -m pytest -q
```

`--apply`는 원문 SHA-256이 일치하는 항목만 갱신한다. 완료되지 않은 자산을
억지로 병합하지 말고, 먼저 `completed/scenario_*.json`이 전체 파일에 존재하는지
확인한다. 릴리스 패치 생성은 이 JSON 검수와 실제 소유 게임의 CPK·EBOOT 검증이
끝난 뒤에만 수행한다.

## 이번 전면 재번역 실행 기록

2026-08-10 기준 시나리오 174개 파일, 170,746개 항목을 모두 새 초안으로
생성하고 공통 JSON에 반영했다. 원문 항목 SHA-256 불일치·누락·제어코드 불일치는
각각 0건이다. 생성 결과가 공백이었던 1,173건은 기존 참고 번역을 임시 유지하고
`notes`에 표시했으며, 모두 사람 검수 전 `draft` 상태로 남겼다.

검수 플래그는 일본어 잔존 454건, 대사창 시각 슬롯 초과 141건, 보호 표식 복원
누락 493건이다. 이 수치는 실패를 숨기지 않고 후속 문맥·길이 검수 대상으로
남긴 것이다. 전체 공통 번들 검증은 176개 파일·197,068개 항목을 통과했고,
자동화 테스트는 `91 passed, 19 subtests passed`였다. 실제 패치 릴리스 전에는
이 플래그를 해소한 뒤 다시 `check_dialogue_review_bundle.py`와 패치 빌드를
실행해야 한다.
