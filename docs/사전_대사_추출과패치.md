# 사전 대사 추출·신규 번역·CPK 리팩

사전 대사는 `CommonData/MtData/MtZkn_KW.cpk`에 들어 있습니다. 이 파일의
141개 멤버는 CPK ITOC/@UTF 표에 기록된 ID·크기 순서로 이어지며, 각 멤버의
내용은 `0x5E` XOR 뒤 `ZKANKYWD` 매직과 `WORD`, `SRCE`, `DSCR`, `DSC2`
태그를 가집니다. `DSCR`과 `DSC2`는 같은 설명의 복사본입니다.

같은 폴더의 `MtV_all_keyword_def.cpk`, `MtZkn_Pt.cpk`, `MtZkn_Rt.cpk`도
대조했지만 이 레코드 매직을 포함하지 않았습니다. 따라서 현재 사전 문장
패치 대상은 `MtZkn_KW.cpk`이며, 나머지 파일은 별도 자산 재번역 범위로
취급합니다.

## 안전한 준비

원본 아카이브는 읽기 전용으로 두고, 본인이 합법적으로 보유·덤프한
`MtZkn_KW.cpk`만 `--cpk`에 지정합니다. 게임 파일, 완성 CPK, 실행 파일,
비밀키는 저장소에 넣지 않습니다. 모든 결과는 `work/` 또는 `output/` 아래에
생성됩니다.

저장소만 내려받은 새 환경에서는 먼저 문자표를 만듭니다. 문자표 원본은
프로젝트 작업 폴더에서 읽고, 저장소에는 게임 파일이 아닌 문자 매핑 JSON만
보관합니다.

```powershell
$env:PYTHONPATH='src'
python scripts/build_dictionary_encoding.py `
  --table 'C:\내 작업\0_STAGE\shift-jis2.tbl' `
  --wreplace 'C:\내 작업\Japanese - Hangul to Kanji.wReplace'
```

## 원문 추출

```powershell
$env:PYTHONPATH='src'
python scripts/extract_dictionary_dialogue.py `
  --cpk 'C:\내 게임 덤프\CommonData\MtData\MtZkn_KW.cpk' `
  --output work/dictionary-source.json
```

추출기는 CPK SHA-256을 기록하고 ITOC의 141행과 실제 XOR 매직·멤버 크기를
대조합니다. 원문은 `sourceText`, 논리 페이로드는 `sourcePayloadHex`, 줄바꿈과
비표준 바이트는 `<BR>`, `<NUL>`, `<Bxx>` 토큰으로 함께 기록됩니다.

## 신규 한국어 번역과 페이로드 생성

기존 번역 JSON을 읽지 않고 원문 JSON만 번역 서비스에 전달합니다. 네트워크가
필요한 단계는 이 단계뿐이며, 서비스가 반환한 번역은 `draft` 또는 CPK 리팩이
필요한 `overflow-repacked`로 표시됩니다. 모든 행은 일본어 원문·한국어
번역·원문 해시·적용 페이로드를 한 쌍으로 가집니다.

```powershell
$env:PYTHONPATH='src'
python scripts/translate_dictionary.py --workers 6
```

`work/dictionary-translation-cache.json`은 재시작용 캐시이며 Git에 올리지
않습니다. 최종 공개 파일은
`translations/dialogue/dictionary_MtZkn_KW.json`입니다. 이전 전용 파일
`translations/dictionary/MtZkn_KW.json`은 호환용 원본 자료로 남아 있습니다.

현재 공개 JSON은 564개 행 모두를 채웠고, 280개는 `draft`, 284개는
`overflow-repacked`로 표시합니다. `overflow-repacked`는 문장을 자른 것이
아니라 태그 길이·멤버 크기·ITOC 크기를 함께 늘린 결과입니다. 자동 번역의
고유명사와 문장 품질은 게임 화면에서 사람 검수해야 합니다.

## CPK 적용과 리팩

```powershell
$env:PYTHONPATH='src'
python scripts/apply_dictionary_patch.py `
  --original 'C:\내 게임 덤프\CommonData\MtData\MtZkn_KW.cpk' `
  --output 'output/dictionary/MtZkn_KW.cpk'
```

실행기는 원본 크기·SHA-256, 564개 원문 페이로드, 태그와 번역 페이로드의
해시를 먼저 확인합니다. 그 다음 긴 한국어 설명에 맞춰 다음을 함께 갱신합니다.

- 태그의 little-endian 길이
- 멤버의 실제 크기와 16바이트 정렬
- CPK ITOC의 `FileSize`·`ExtractSize`

리팩 후 새 CPK를 다시 추출해 모든 태그와 적용 페이로드를 재검사합니다.
원본 파일은 열기만 하며 덮어쓰지 않습니다.

## 통합 실행기 연결

`config/release-patch.json`에는 `dictionary-json` 한 항목이 등록되어 있습니다.
따라서 xdelta·시나리오·전투·메뉴·사전·eboot·맵을 한 번에 별도 출력 트리에
만들려면 [통합 패치 실행](통합_패치_실행.md)의 명령을 사용합니다. 통합
실행기는 사전 JSON 실행기를 내부에서 호출하고 결과 크기·SHA-256을 매니페스트와
대조합니다.

사전 CPK를 별도로 적용할 때도 위의 독립 명령을 사용하면 되며, 두 방식 모두
Vita3K 입력 폴더에 직접 복사하지 않습니다. 실기 Vita용 패키지 서명은 이
저장소 범위가 아니므로 실행기에서 차단합니다.
