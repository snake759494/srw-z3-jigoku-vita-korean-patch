# 시나리오 재번역 v3 실행 절차

시나리오 파일만 다시 만들 때 사용하는 재현 가능한 절차다. 게임 롬·CPK·EBOOT는
저장소에 포함하지 않으며, 사용자가 소유한 게임에서 추출한 JSON만 입력으로 사용한다.

## 기본 실행

저장소 루트에서 다음 명령을 실행한다.

```powershell
$env:PYTHONPATH = ".;src"
python scripts/retranslate_scenario_v3.py `
  --glossary translations/retranslation/scenario_glossary_v2.json `
  --series-reference translations/retranslation/series_reference.json `
  --baseline-commit 156096c `
  --report work/retranslation-v3/qa-dry-run.json
```

첫 실행은 실제 파일을 바꾸지 않고 결과를 확인한다. `summary`의 기준 누락과 원문
불일치가 0이고 `totals.after`의 `japaneseRemainder`, `controlMismatch`,
`lengthOverflow`, `empty`가 0인지 확인한 뒤 적용한다.

```powershell
python scripts/retranslate_scenario_v3.py `
  --glossary translations/retranslation/scenario_glossary_v2.json `
  --series-reference translations/retranslation/series_reference.json `
  --baseline-commit 156096c `
  --apply `
  --report work/retranslation-v3/qa-apply.json
```

이 명령은 `translations/dialogue/scenario_*.json`만 갱신한다. 모든 항목은 `draft`
상태로 남고, `notes`에는 선택된 후보 출처와 정규화된 용어가 기록된다. 최종 검수 뒤
사람이 `translationStatus`와 `reviewer`를 바꾼다.

`--series-reference`는 기본값으로도 연결되어 있으며, 32개 참전작의 일본어 공식
제목과 한국어 표기를 정규화 후보에 보충한다. 인물 관계와 말투를 자동으로 덮어쓰지는
않고, 장면의 화자·청자를 사람이 검토할 때 `series_reference.json`의 지침을 함께
확인한다.

## 기준 번역 커밋

기본 기준은 저장소의 `156096c`에 있는 이전 손번역 JSON이다. 이 값은 문장 흐름과
작품별 호칭을 확인하기 위한 로컬 참고 자료이며 정답으로 간주하지 않는다. 얕은
클론에서 해당 커밋이 없으면 다음처럼 기준 JSON 폴더를 직접 지정할 수 있다.

```powershell
python scripts/retranslate_scenario_v3.py `
  --baseline-root "D:\\Z\\psvita\\시옥편-한글패치-기준" `
  --apply
```

기준 폴더에는 같은 파일명(`scenario_*.json`)을 두고 `entries[].entryId`와
`sourceText`를 유지해야 한다.

## 특정 파일만 시험

```powershell
python scripts/retranslate_scenario_v3.py `
  --asset scenario_STG0001a.json `
  --asset scenario_DLC0301.json `
  --report work/retranslation-v3/sample.json
```

## QA와 CPK 재삽입

```powershell
$env:PYTHONPATH = ".;src"
pytest -q
python scripts/check_dialogue_review_bundle.py
```

QA가 통과해도 실제 CPK에 넣기 전에는 원본 게임 파일의 버전, 대사창 줄 수, Vita3K
화면을 확인한다. 시나리오 CPK 재패킹은 기존 통합 패치 실행기의 시나리오 입력으로
이 JSON을 사용한다. 이 문서와 코드는 번역 데이터의 출처를 외부 서비스로 전송하지
않으며, 본인이 소유한 게임의 추출물에만 적용한다.
