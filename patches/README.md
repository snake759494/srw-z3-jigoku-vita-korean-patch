# 공개 릴리스 델타

`release/vita3k/main/`과 `release/vita3k/dlc/`에는 자기 소유 원본에 적용할 xdelta3 델타만 보관합니다. 원본 게임 파일이나 완성 게임 파일은 포함하지 않습니다.

목록과 원본·결과·델타 SHA-256은 [`config/release-patch.json`](../config/release-patch.json)에 있으며, 실제 적용은 [`통합 패치 실행 설명서`](../docs/통합_패치_실행.md)의 실행기를 사용합니다. 기존 배치 파일이나 출처 불명 `xdelta.exe`를 실행하지 마세요.
